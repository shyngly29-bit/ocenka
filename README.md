# Баллы на уроке

Формативное оценивание (ФО) прямо на уроке, удобно с телефона и с компьютера.
Сайт: https://shyngly29-bit.github.io/ocenka/

- Четыре кнопки: Қайталау, Жаңа тақырып (без баллов), Талқылау, Бекіту; внутри этапа может быть несколько заданий. ҚМЖ, тема, дата, история и итоги — в «⌂ Басты».
- У каждого дескриптора свои уровни (0/1/2 или 0/1). Одно нажатие ставит уровень, повторное ничего не меняет, есть «Снять отметку» и «Отменить».
- Статусы: Не проверен, Черновик, Проверен, Отсутствовал. Черновик в итог для переноса не попадает.
- Каждый урок хранит свою копию критериев. История уроков по классу и дате.
- Итоги для BilimClass: исходный порядок списка, копирование «ФИО + балл», Excel.
- Импорт списка из Excel / Word / BilimClass с предпросмотром.
- Готовый шаблон: 9-сынып, физика, «Ньютонның бірінші заңы» (2 + 8 + 0 = 10 баллов). Старые уроки с 4 этапами остаются в истории.
- Данные хранятся в браузере (localStorage). «☰ → Резервная копия» сохраняет всё в один файл.

Экран «⌂ Басты»: продолжить оценивание, класс и урок, ҚМЖ, импорт, шаблоны, история, нәтижелер. Рабочий экран: этапы Басы · Ортасы · Соңы, список и карточка; на телефоне снизу «Оқушылар» и «Келесі →».

Клавиши на компьютере: ↑↓ дескриптор, 0–9 уровень, Del снять, → / N следующий, Shift+N непроверенный, ← предыдущий, [ ] этап, Ctrl+Z отменить, / поиск.

Файлы: `index.html` — страница для GitHub Pages; `ocenka.html` — та же программа для ссылки claude.ai.
