# Баллы на уроке

Оценивание учеников по дескрипторам прямо на уроке (удобно с телефона).

- Загрузка списка учеников из Excel (.xlsx/.xls/.csv), Word (.docx) или .txt
- Нажали на ученика → нажали на дескриптор → баллы суммируются
- Потолок баллов за урок и свои пороги оценок (или 10-балльная / 5-балльная / %)
- Несколько классов, у каждого свой список и баллы
- Итоги для переноса в BilimClass, копирование оценок, экспорт в Excel

Откройте `index.html` в браузере. Данные хранятся в браузере (localStorage).
